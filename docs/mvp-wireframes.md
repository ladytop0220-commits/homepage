# Émelle — MVP 와이어프레임 & 화면 설계

**버전**: v0.1
**작성일**: 2026-05-21
**대상**: MVP Phase 1 (4~6주 출시 목표)

---

## 0. MVP Phase 1 범위 정의

### ✅ 포함
- 메인 페이지 + 브랜드 소개
- 제품 카탈로그 (현재 1종 — 에멜 세라믹 팬 28cm)
- 회원가입 (B2C 일반 회원만)
- 비회원 주문
- 장바구니 + 주문/결제 (PG 1종: 토스페이먼츠 권장)
- 마이페이지 (주문 조회, 회원정보)
- 정책 페이지 3종
- **어드민**: 주문 관리, 제품 관리, 단순 재고
- **카카오톡 옵션 B**: 운영자가 채팅 텍스트 → LLM 파싱 → 주문 등록
- 한국어 UI

### ⏸️ Phase 2로 미룸
- B2B 도매가 / 사업자 회원 가입 (정책·DB 구조는 미리 설계)
- 무통장입금 / 후불결제
- 영어 UI
- 입출고 이력 추적, 안전재고 알림
- 쿠폰 / 적립금
- 발주 시스템 (공급업체 DB, PDF 발주서)
- 전자세금계산서 API (수동 발급 유지)
- 알림톡 / SMS 다채널 (이메일만 우선)
- 미수금 관리

### 📱 디바이스 우선순위
- **고객 페이지**: 모바일 우선 (Mobile-first, 한국 이커머스 80%+ 모바일)
- **어드민 페이지**: 데스크탑 우선 (PC에서 운영)

## 3. 핵심 사용자 플로우

### 🛒 플로우 1 — 비회원 주문 (가장 일반적)
```
[홈] → [제품 목록] → [제품 상세] → 수량 선택 → [장바구니에 담기]
  → [장바구니] → "비회원으로 주문" → [주문서 작성]
  → 수령인 정보 + 배송지 + 이메일 입력
  → 약관 동의 → "결제하기"
  → [토스페이먼츠 결제창] → 결제 완료
  → [주문 완료 페이지] (주문번호 + 이메일 발송 안내)
  → [선택] "회원가입하면 다음에 빠르게 주문 가능" 유도 CTA
```

### 💬 플로우 2 — 카톡 채널 주문 (정형 Q&A 방식)

**현재 운영 방식**: 카카오톡 채널 "생활의 여유"는 자유 텍스트가 아니라 **고정된 1~7번 질문 양식**을 안내하고, 고객이 각 번호에 답을 적어 보내는 구조.

```
[채널 자동 응답] 주문 양식 안내 (확정)

안녕하세요 😊
주문을 원하시는 경우 아래 내용을 작성해서 보내주세요.

  1. 지점명
  2. 주문 수량
  3. 담당자 성함
  4. 핸드폰 번호 or 지점 전화번호
  5. 이메일 주소
  6. 카드 번호 / 유효 기간     ⚠️ 보안상 결제 링크 발송으로 전환 권고
  7. 거래명세서 발행 여부
     (발행 원하시는 경우 이메일 주소를 꼭 작성해주세요.)

확인 후 순차적으로 안내 도와드리겠습니다 💛
```

> ⚠️ **6번 카드 번호 수집은 PCI DSS·개인정보보호법 위반 소지가 큽니다.** 빠른 시일 내 다음 중 하나로 전환 강력 권고:
> - 카카오톡으로 토스페이먼츠 결제 링크 발송 (가장 권장)
> - "카드/계좌이체/무통장 중 선택"으로만 받고 결제는 별도 채널
>
> 어드민 인테이크 화면에서는 카드번호가 들어오면 즉시 마스킹 후 **DB에 절대 저장하지 않음**.

  ↓ (고객이 각 번호에 답을 작성하여 전송)

[운영자] 어드민 /admin/kakao-intake 페이지에서
  → "새 주문 등록" 클릭 → 답변 텍스트 붙여넣기
  → 시스템이 1~7번 패턴으로 자동 파싱
  ↓
[파싱 결과] 각 번호별 필드에 자동 매핑
  - 1번 → 지점명 (B2B 고객 구분)
  - 2번 → 주문 수량 (현재 단일 상품 EM-CUI-PAN-28 가정)
  - 3번 → 담당자 성함
  - 4번 → 연락처 (모바일/유선 자동 판별)
  - 5번 → 이메일
  - 6번 → 결제 방식 (카드/계좌/무통장) — 카드번호 검출 시 자동 마스킹
  - 7번 → 거래명세서 발행 여부 + 수신 이메일
  ↓
[운영자] 자동 채워진 폼 검토 (필요 시 수정)
  → "주문 확정"
  ↓
[시스템] orders 테이블 INSERT (source='kakao_channel', branch_name=...)
  → 토스 결제 링크 발송 (카드의 경우) / 무통장 안내
  → 거래명세서 요청 플래그 세팅
```

**파싱 단계**:
- 1차 — 정규식 (라인 시작 `^\d+[.)]\s*` 패턴) 으로 번호별 답변 분리. 외부 API 불필요.
- 2차 (Phase 2) — Claude API로 답변 정규화 (예: "지점장 김미정" → 담당자명 추출, 연락처 포맷 통일).

**Phase 3 → 옵션 A 챗봇 전환**: 카카오 i 오픈빌더 도입 시 양식이 버튼·블록으로 분기되어 더 빠른 UX.

### 📦 플로우 3 — 어드민 출고 처리
```
[대시보드] 신규 주문 N건 표시 → 클릭
  ↓
[주문 목록] 상태 "신규" 필터
  ↓
[주문 상세] 내용 확인
  → 송장 번호 입력 → "출고 완료" 클릭
  ↓
[시스템] 재고 차감 → 고객 이메일 알림 발송
  → 주문 상태 "배송중"으로 변경
```

### 👤 플로우 4 — 회원가입 + 첫 주문
```
[홈] → [회원가입] → 이메일·비밀번호·이름·휴대폰
  → 이메일 인증 → 가입 완료
  → [제품 상세] → [장바구니] → [회원 주문]
  → 저장된 정보 자동 입력 → 결제 → 완료
```
